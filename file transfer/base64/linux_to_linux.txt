base64 shell -w 0

Now, we can copy this base64 string,
 go to the remote host, and use base64
 -d to decode it, and pipe the output into
 a file:

user@remotehost$ echo f0VMRgIBAQAAAAAAAAAAAA
IAPgABAAAA...SNIO...lIuy9iaW4vc2gAU0iJ51JXSInmDwU
 | base64 -d > shell
