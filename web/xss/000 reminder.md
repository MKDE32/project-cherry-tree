# Stored (Persistent) XSS	
- most critical type
- occurs when user input is stored on the back-end database

# Reflected (Non-Persistent) XSS	
- user input is displayed on the page after being processed by the backend server
- without being stored permanent

# DOM-based XSS	
- Non-Persistent
- user input is directly shown in the browser
- is completely processed on the client-side
