# OVERVIEW
`apt list --upgradeable` listet packete die upgedatet werden können  
`apt list --installed` listet installierte pakete



# UPDATE
`sudo apt-get update` update repository  
`sudo apt upgrade` software upgrade  
`sudo apt full-upgrade` software & kernel upgrade



# INSTALL
`apt install appname -y` example  
`-y` yes to all  
`-f` fix dependencies / update package manager



# DELETE

`apt autoremove` überflüssiges entfernen  
`apt remove programm` package deinstall  
`apt purge programm` package deinstall inklusive userdata
