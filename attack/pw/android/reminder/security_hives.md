# SECURITY DATABASES
## PASSWORD.KEY
`gatekeeper.password.key`
- password or pin


## PATTERN.KEY
`gatekeeper.pattern.key`
- pattern


## LOCKSETTINGS.DB
`locksettings.db`
- lockscreen type
- policys
- encryption status
- user settings


## .DB-WAL
`locksettings.db-wal`
- not saved changes for `.db`
- if only `.db` is changed, changes in `.db` can be undone or messed up the database after reboot.


## .DB-SHM
`locksettings.db-shm`
- shared memory index for `.db-wal`
