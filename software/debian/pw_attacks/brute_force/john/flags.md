| Flag                | Purpose                                                    |
| ------------------- | ---------------------------------------------------------- |
| `--wordlist=<file>` | Use a specific wordlist for password guessing.             |
| `--rules`           | Apply word-mangling rules to generate password variations. |
| `--incremental`     | Incremental/brute-force mode.                              |
| `--format=<type>`   | Specify the hash format (e.g., NTLM, bcrypt, MD5).         |
| `--show`            | Display already-cracked passwords from the pot file.       |
| `--session=<name>`  | Save progress under a session name.                        |
| `--restore`         | Resume a previously interrupted session.                   |
| `--fork=<n>`        | Run multiple cracking processes in parallel on CPUs.       |
| `--mask=<pattern>`  | Use a mask attack (e.g., known password structure).        |
| `--users=<user>`    | Target specific user accounts in the hash file.            |
| `--groups=<group>`  | Target specific groups.                                    |
| `--status`          | Show current cracking status.                              |
| `--stdout`          | Generate candidate passwords without cracking.             |
| `--pot=<file>`      | Use a custom pot file for storing cracked hashes.          |
