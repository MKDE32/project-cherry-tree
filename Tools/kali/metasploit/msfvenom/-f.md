# Binaries
```
-f exe        # Windows executable
-f elf        # Linux binary
-f macho      # macOS binary
```

# Web / scripting
```
-f php        # PHP script
-f asp        # ASP script
-f aspx       # ASPX script
-f jsp        # Java JSP
-f war        # Java web archive (deploy on Tomcat)
```

# Shellcode / dev use
```
-f raw        # raw shellcode (no formatting)
-f c          # C array
-f python     # Python bytes
-f ruby       # Ruby format
-f perl       # Perl format
-f powershell # PowerShell script
```

# Other useful
```
-f js         # JavaScript
-f vba        # VBA macro (Office)
-f dll        # Windows DLL
```
